Detailed Description

Computes the column-pivoted economy QR decomposition of a real M-by-N matrix A.

A * P = Q * R

where P is the column permutation described by jpvt, Q has orthonormal columns, and R is upper trapezoidal with |R(1,1)| >= |R(2,2)| >= ... along columns selected by decreasing pivoted norm. For an M-by-N matrix, Q has dimensions M-by-min(M,N), while R has dimensions min(M,N)-by-N.
